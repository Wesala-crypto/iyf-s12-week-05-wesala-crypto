# Week 5 – DOM Manipulation & Interactive To-Do List

A practical JavaScript project developed as part of the **IYF WeCan Academy – Season 12** training programme.

This project demonstrates how JavaScript interacts with HTML and CSS to create dynamic, interactive web pages using the Document Object Model (DOM).

## Project Overview

The project focuses on DOM manipulation, event handling, event bubbling, event delegation, and form validation.

It includes an interactive To-Do List application, DOM practice exercises, and five daily coding challenges.

## Features

### 1. Interactive To-Do List
- Add tasks using the Add button or Enter key.
- Mark tasks as completed.
- Delete tasks.
- Filter tasks by All, Active, and Completed.
- Display the number of remaining tasks.
- Clear all completed tasks.
- Edit tasks by double-clicking them.
- Save edits with Enter or cancel with Escape.

### 2. DOM Practice
The `dom-practice.html` page demonstrates:
- Selecting and traversing DOM elements.
- Changing text, HTML content, and attributes.
- Creating, inserting, and removing elements.
- Handling browser events.
- Understanding event bubbling.
- Using event delegation.
- Validating and handling form submissions.

### 3. Daily Challenges

| File | Challenge |
|---|---|
| `day-1.html` | Random Hex Color Generator |
| `day-2.html` | Dynamic Numbered Paragraphs |
| `day-3.html` | Image Removal and Visibility Toggle |
| `day-4.html` | Content Copying and Drag-and-Drop |
| `day-5.html` | Dark Mode Toggle |

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Wesala-crypto/iyf-s12-week-05-wesala-crypto.git
   ```

2. Open the project folder.

3. Open `index.html` in your web browser to use the To-Do List.

4. Open `dom-practice.html` to explore the DOM exercises.

5. Open any file inside `daily-challenges/` to view its challenge.

No additional packages or installations are required.
